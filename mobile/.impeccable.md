## Design Context

### Users
Travelers on a group trip (school/club/corporate FAM groups run by a travel agency). They join a trip by PIN or link and use the app on their phone while traveling: checking today's plan, the next event, flight status, documents, and sharing photos. Used on the move, often one-handed, sometimes offline, sometimes at night before an early flight. Not admins — the agency runs the desktop web app; this is the traveler's companion.

### Brand Personality
Same brand as the web app (**precise, editorial, uncompromising**) but **warmer on the road**. Three words: **confident, clear, on-your-side.** The interface should feel like a well-briefed tour leader: knows exactly what's next, never fussy, quietly premium. Emotions to evoke: calm confidence ("I know where I need to be"), a little anticipation before a trip, delight when photos come in.

### Aesthetic Direction
- Dark-first with a fully AA-compliant light theme (`constants/theme.ts` tokens: `bg/card/elevated`, `teal` accent, `tealText/greenText/amberText/redText` for colored text).
- **Type**: SF (system) for all UI and body; **Barlow Condensed** for brand display moments only. Tiered: Black 900 uppercase for short labels, kickers, day names, IATA/route codes, countdown numbers; ExtraBold 800 sentence-case for long titles (welcome/auth/sheet titles); trip-name heroes ExtraBold uppercase. Never Barlow on native headers, body, buttons, or list text. Micro-labels always carry a tight `lineHeight` (Barlow's line box is tall).
- **Accent restraint**: teal only for active states, primary CTAs, live indicators, kickers. `onAccent` (black) text on teal fills.
- **Surfaces**: cards `R.xl` (22); `R["2xl"]` only the Home hero carousel. `shadow("card")` in light mode; dark mode relies on value contrast + `border`. Over-photo pills use `glass`/`glassBorder`.
- **Native-first shell**: NativeTabs (liquid glass), native context menus, native large titles on root-stack pushes; `CollapsingHeader` on tab screens (UIKit large-title link is dead inside NativeTabs).
- Anti-references: pastel consumer travel apps, gradient/glow "AI" aesthetics, generic Material, card-inside-card layouts, side-stripe accents.

### Design Principles
1. **Next thing first** — the screen answers "what's next and where" before anything else; density is fine, ambiguity is not.
2. **Same system everywhere** — tokens and `components/ui/*` (MicroLabel, Pill, Avatar, IconCircleButton, EmptyState, DragHandle, CollapsingHeader) over hand-rolled variants; no new one-offs.
3. **Warm through motion and copy, not color** — FadeIn stagger (≤ 6 × 60ms), ScalePress on cards, sentence-case, plain-spoken copy; the palette stays disciplined.
4. **Legible on a bus at night** — AA contrast in both themes, type floor 10pt, 44pt touch targets, labels on every icon-only control.
5. **Native where it counts, custom where native breaks** — prefer platform behavior; when UIKit can't deliver (tab-nested large titles), replicate it faithfully rather than approximating.
